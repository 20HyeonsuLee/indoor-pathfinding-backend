# 관리자 웹 3D 뷰어 — FPS 모드 가이드

관리자가 포인트클라우드 내부를 1인칭 시점으로 탐색하며 노드/엣지/POI를 편집하는 기능이다. 복도 안에서 호실 명패를 확인하며 POI를 찍을 때 유용하다.

## 두 가지 모드

| | Orbit 모드 (기본) | FPS 모드 |
|---|---|---|
| 진입 | 기본 | 3D 뷰 더블클릭 |
| 탈출 | — | ESC |
| 시야 회전 | 좌클릭 드래그 | 마우스 이동 (Pointer Lock) |
| 이동 | 우클릭 드래그 / WASD | WASD |
| 상승/하강 | — | Q / E |
| 부스터 | — | Shift (3배 속도) |
| 커서 | 보임 | 숨김 + 십자선 |

## 단축키

### 이동

| 키 | 동작 |
|---|---|
| W / ↑ | 전진 (마우스 방향) |
| S / ↓ | 후퇴 |
| A / ← | 좌측 이동 |
| D / → | 우측 이동 |
| Q | 상승 |
| E | 하강 |
| Shift | 누르고 있으면 3배 속도 |

### 편집 모드 전환

| 키 | 모드 | 설명 |
|---|---|---|
| 1 | 보기 | 편집 없이 탐색만 |
| 2 | 노드 추가 | 클릭으로 WAYPOINT 노드 배치 |
| 3 | 엣지 추가 | 노드 클릭-클릭으로 수평 엣지 연결 |
| 4 | 선택 | 노드/엣지 선택 → Delete로 삭제 |
| 5 | 계단 연결 | 노드 클릭-클릭으로 VERTICAL_STAIRCASE 엣지 |
| 6 | 엘리베이터 연결 | 노드 클릭-클릭으로 VERTICAL_ELEVATOR 엣지 |
| 7 | POI 배치 | 노드 클릭으로 POI 지정 |

### 기타

| 키 | 동작 |
|---|---|
| T | 자동연결 ON/OFF 토글 |
| Z | 이전 층으로 이동 |
| X | 다음 층으로 이동 |
| Space | 현재 위치(발밑)에 노드/POI 배치 (FPS 전용) |
| Delete / Backspace | 선택 항목 삭제 |
| ESC | FPS 탈출 / 연결 취소 / 선택 해제 |

## FPS 배치 방식

### 클릭 배치
십자선(에임)이 가리키는 위치에 배치. 바닥 평면과의 교차점에 노드가 생성된다.

### Space 배치 (FPS 전용)
카메라 현재 위치의 발밑(바닥 높이)에 노드를 배치한다. 복도를 걸으며 일정 간격으로 Space를 누르면 빠르게 노드를 찍을 수 있다.

## 계단/엘리베이터 연결

5번(계단) 또는 6번(엘리베이터) 모드에서 층을 넘나들며 노드를 연결한다.

```
5번 모드 진입
    ↓
1층 계단 입구 노드 클릭 (시작점)
    ↓
Z/X로 2층 이동
    ↓
2층 계단 출구 노드 클릭 → 1↔2 수직 엣지 생성 (체이닝)
    ↓
Z/X로 3층 이동
    ↓
3층 노드 클릭 → 2↔3 수직 엣지 생성 (체이닝)
    ↓
ESC로 종료
```

- 클릭할 때마다 이전 노드와 수직 엣지가 생성되고, 현재 노드가 다음 시작점이 된다
- 양쪽 노드는 자동으로 PASSAGE_ENTRY / PASSAGE_EXIT 타입으로 변경
- 엣지 타입은 5번=VERTICAL_STAIRCASE, 6번=VERTICAL_ELEVATOR
- A* 길찾기에서 선호도에 따라 가중치 적용 (엘리베이터 0.5배, 계단 0.8배)

## 모드바 UI

화면 하단에 1~7번 모드가 게임의 무기 전환 UI처럼 표시된다.

- 활성 모드는 밝은 배경 + 흰색 테두리로 강조
- 자동연결 상태 (T: ON/OFF), 현재 층 (Z/X: 층 이동), 부스터 안내 표시
- 계단/엘리베이터 연결 중이면 "연결 중" 안내 표시
- 클릭으로도 모드 전환 가능 (키보드 단축키와 동일)

## 기술 구현

### Pointer Lock API
- `canvas.requestPointerLock()` — 더블클릭 시 커서 숨김 + FPS 진입
- `document.exitPointerLock()` — ESC 시 브라우저가 자동 해제
- `pointerlockchange` 이벤트로 viewMode("fps"/"orbit") 동기화

### 카메라 제어
- `mousemove`의 `e.movementX/Y`로 yaw/pitch 계산 (클릭 불필요)
- `camera.quaternion`을 Euler(pitch, yaw, 0, "YXZ")로 직접 설정
- OrbitControls는 FPS 모드에서 비활성화, orbit 모드에서만 사용
- 이동 속도는 delta time 기반 (초당 5m, Shift 시 15m)

### 에임 보정
- Pointer Lock 상태에서 브라우저가 `clientX/Y`를 고정하므로, R3F의 raycast가 화면 중앙이 아닌 곳을 타겟팅하는 문제
- `useFrame`에서 매 프레임 `state.pointer.set(0, 0)` + `raycaster.setFromCamera`로 화면 중앙 강제

### 좌표계
- RTAB-Map → Three.js: X축 반전 + Y↔Z 스왑
- PLY, 노드, POI, 에임 클릭 모두 동일한 변환 적용
- `apiToThree` / `threeToApi` 함수로 통일
