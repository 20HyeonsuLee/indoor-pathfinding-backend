# 연구노트 6회차 - 통합 테스트 및 최종 검증

> **프로젝트명**: 3D 스캔 데이터 기반 실내 내비게이션 시스템
> **소속**: 한국기술교육대학교 컴퓨터공학부
> **담당**: 백엔드 서버

---

## 연구 배경

개별 기능이 동작하는 것과 전체 시스템이 실제 데이터에서 안정적으로 동작하는 것은 다른 문제이다. 이번 회차에서는 실제 건물 스캔 데이터(school.db, 89MB)를 사용하여 전체 플로우를 검증하고, 성능을 측정하였다.

---

## 작업 내용

### 통합 테스트 및 배포 자동화

공간 데이터(PostGIS)를 사용하므로 인메모리 DB로는 테스트가 불가능하다. Testcontainers를 도입하여 테스트 시 실제 PostgreSQL+PostGIS 컨테이너를 자동으로 띄워 운영 환경과 동일한 조건에서 검증하였다. A* 알고리즘 단위 테스트(6개 케이스)와 API 통합 테스트(5개 모듈) 전체 PASS. GitHub Actions로 코드 Push → 빌드 → 배포를 자동화하였다.

### 전체 플로우 검증

**관리자**: 건물 등록 → 층 등록 → .db 업로드 → 경로 추출(~30초) → 그래프 생성(142노드, 198엣지)

**사용자**: 이미지 3장 위치 추정(confidence 0.87) → "컴공세미나실" 검색 → A* 경로 탐색 → 턴바이턴 안내("3m 직진 → 좌회전 → 엘리베이터로 1층 이동 → 목적지 도착")

### 성능 측정

| 기능 | 응답 시간 | 비고 |
|------|----------|------|
| A* 길찾기 (142노드) | ~50ms | 건물 단위 그래프는 충분히 빠름 |
| VPS 위치 추정 (3장) | ~800ms | 네트워크 + VPS 처리 포함 |
| 스캔 DB 주변 이미지 조회 | ~200ms | SQLite 직접 읽기 |
| 경로 추출 파이프라인 | ~30s | 비동기 처리로 사용자 대기 없음 |

## 연구 결과 요약

| 연구 목표 | 달성 | 방법 |
|-----------|------|------|
| 스캔 DB → 경로 그래프 자동 추출 | O | 7단계 파이프라인 → PathNode/PathEdge 변환 |
| 선호도 반영 최적 경로 탐색 | O | A* + 엣지 가중치 (최단/엘리베이터/계단) |
| 카메라 이미지 위치 추정 연동 | O | VPS 리버스 프록시, 수동 입력 폴백 |
| 멀티플로어 길찾기 | O | VerticalPassage 수직 엣지로 층간 탐색 |
| 스캔 DB 참조 이미지 추출 | O | 포즈 블롭 파싱 + 3섹터 방향 분류 |

**핵심 성과**: 비콘·Wi-Fi AP 없이 스마트폰 카메라만으로 실내 스캔 → 자동 경로 생성 → 위치 추정 → 길찾기가 가능한 시스템을 구현하였다.
